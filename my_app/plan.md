## 4. 화면 구성

**공통**
- 상단 탭 3개: 해시 라우팅 `#heroes` `#tiers` `#stats`
- 헤더: 제목, 출처 배지, 라이트/다크 전환
- 영웅 상세 패널: 어느 화면에서든 영웅을 누르면 열림
  - 내용: 이름, 등급, 병종, 역할, 티어, 특징, 같은 병종·티어의 영웅
  - 데스크톱에서는 오른쪽 사이드 패널, 모바일에서는 하단 시트

**① 영웅 도감 `#heroes`**
- 필터
  - 등급·병종·역할은 칩으로 여러 개 선택
  - 티어는 범위로 선택 (예: A 이상)
  - 이름·특징 검색, 초기화 버튼
- 정렬: 티어순(기본), 등급순, 이름순
- 보기 전환: 카드 그리드 / 표
- 결과 건수 표시
- 카드 구성: 이니셜 아바타, 이름, 등급 배지(UR·SSR·SR 색 구분), 병종 아이콘, 역할, 티어, 특징 한 줄

**② 티어표 `#tiers`**
- 행은 티어 S+~D, 열은 보병·전차·헬기인 매트릭스
- 칸마다 영웅 칩 (등급 색 테두리)
- 등급 필터(UR·SSR·SR)를 고르면 나머지 칩이 흐려짐
- 모바일에서는 병종별 세로 목록으로 전환

**③ 분포 차트 `#stats`**
- 요약 수치: 전체 31명, UR 15 / SSR 12 / SR 4, 병종 3개
- 등급 × 병종 누적 막대
- 티어 분포 막대 (S+~D, 등급별 누적)
- 역할 비율 도넛 (공격·방어·버프)
- 병종별 평균 티어 점수 (S+=8 … D=1)
- 차트 항목을 누르면 영웅 도감으로 이동하고 그 조건의 필터가 걸림 (예: 헬기 × UR)

## 5. UI / UX

- **색상:** 군사·전략 게임 분위기의 짙은 청회색을 기본으로 쓰고, 강조색은 하나만 둠
  - 등급색은 의미색으로 따로 둠: UR 주황, SSR 보라, SR 파랑
  - 티어색은 S+에서 D로 갈수록 진한 색에서 옅은 색으로 바뀜
- **테마:** 모든 색을 토큰으로 정의하고 다크모드는 토큰 재정의로 처리. 마지막 선택은 브라우저에 기억
- **모션:** 막대가 자라는 효과와 숫자 카운트업만 사용하고, 최초 진입 때 1회만 실행. 시스템에서 '동작 줄이기'를 켠 경우 생략
- **반응형:** 400px 폭까지 지원, 가로 스크롤 없음 (표와 매트릭스만 내부 스크롤 허용)
- **접근성:** 칩과 카드는 키보드로 조작 가능, 포커스 표시. 색만으로 구분하지 않고 등급·티어 글자를 함께 표시

## 6. 테스트 (UI 제외, 로직만)

1. `index.html`의 데이터가 `data/heroes.json`과 일치하는지
2. 데이터 무결성: 이름 중복 없음, 모든 값이 허용 목록 안에 있는지, 31명·UR 15·SSR 12·SR 4
3. 필터: 등급·병종·역할 다중 선택, 티어 범위, 검색의 조합
4. 정렬: 티어순, 등급순, 이름순 (동률은 이름 순)
5. 티어표 그룹핑: 칸별 영웅 수 합계가 31명
6. 분포 집계: 등급 × 병종, 티어 분포, 역할 비율, 평균 티어 점수
7. 인라인 스크립트 문법 검사
